# Сайт «Домик рыбака у речки» одним файлом index.html

## Что получится
- Один файл `index.html` в разделе Files. Его можно загрузить на любой хостинг: Netlify, GitHub Pages, Тильда (через HTML-блок), обычный хостинг и т.д.
- Внутри всё, что есть на сайте сейчас: главный экран, «О месте», домики с ценами, рыбалка, галерея, отзывы, форма бронирования, контакты.
- Фото встроены прямо в файл, поэтому ничего не потеряется при загрузке.
- Форма бронирования, как и сейчас, только показывает «Спасибо!» — заявки никуда не отправляются.
- Сам сайт в Lovable не меняется.

## Технические детали
- Открыть текущую страницу в браузере в песочнице и взять готовую разметку после отрисовки.
- Вставить собранный CSS (Tailwind + шрифты Google Fonts через `<link>`) внутрь `<style>`.
- Перевести изображения из `src/assets` в base64 и вставить в атрибуты `src`, предварительно уменьшив их до разумного размера, чтобы файл весил немного.
- Убрать скрипты React; форму сделать маленьким встроенным скриптом, который заменяет её на сообщение «Спасибо».
- Сохранить в `/mnt/documents/index.html`, открыть его в браузере и проверить, что всё выглядит как оригинал (на компьютере и телефоне).
